# php-framework-app

Application construite sur [`adrien/php-framework`](../php-framework) (repository Composer local `path`, voir `composer.json`).

Demarrage rapide :

```bash
make install
make up
```

Puis ouvrir `http://localhost:8092` (port configurable dans `.env`, cle `APP_PORT`).

Voir [CLAUDE.md](CLAUDE.md) pour les conventions du projet, et la documentation du framework dans [`../php-framework/docs/index.html`](../php-framework/docs/index.html) pour l'architecture (routing, Controller/Service/Repository, plugins, CLI...).
