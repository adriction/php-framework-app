Modal & tooltip

assets/css/framework/components/overlay.css, utilise --z-overlay/--z-modal/--z-tooltip (tokens). Rendu live : /styleguide.

Modal

<button class="btn btn-primary" data-toggle="modal" data-target="#demo">Ouvrir</button>

<div class="modal" id="demo">
    <div class="modal-dialog">
        <div class="modal-content">
            <div class="modal-header">
                <span class="modal-title">Titre</span>
                <button class="btn-close" data-dismiss="modal"></button>
            </div>
            <div class="modal-body">...</div>
            <div class="modal-footer">
                <button class="btn btn-outline-secondary" data-dismiss="modal">Annuler</button>
                <button class="btn btn-primary">Confirmer</button>
            </div>
        </div>
    </div>
</div>

Le backdrop (.modal-backdrop) est créé et géré automatiquement par le JS — pas besoin de le déclarer dans le HTML (voir JavaScript). .modal-dialog-sm / .modal-dialog-lg pour ajuster la largeur.

Tooltip

<button class="btn btn-outline-secondary tooltip" data-tooltip="Info complémentaire">
    Survoler moi
</button>

Pur CSS (::before/::after + attr(data-tooltip)), affiché au survol/focus — aucun JS de positionnement requis. .tooltip-bottom pour l'afficher sous l'élément plutôt qu'au-dessus.
