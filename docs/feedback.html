Badges

assets/css/framework/components/badges.css — pastilles de statut courtes.

<span class="badge badge-success">Actif</span>
<span class="badge badge-danger-soft">Bloqué</span>
<span class="badge-dot badge-dot-success"></span> En ligne
ClasseRôle
.badge-{primary,secondary,success,danger,warning,info}Pastille pleine, texte inverse
.badge-{couleur}-softFond pâle, texte coloré — plus discret dans une liste dense
.badge-dot (+ .badge-dot-{couleur})Point de statut sans texte, à placer devant un libellé

Alertes

assets/css/framework/components/alerts.css — bandeau de message avec bordure gauche accentuée.

<div class="alert alert-danger alert-dismissible">
    <div class="alert-body">
        <div class="alert-title">Erreur</div>
        Une erreur est survenue.
    </div>
    <button class="btn-close" aria-label="Fermer" data-dismiss="alert"></button>
</div>
ClasseRôle
.alert-{success,danger,warning,info}Fond doux, bordure gauche accentuée de la couleur
.alert-title / .alert-bodyStructure interne
.alert-dismissible + .btn-closeBouton de fermeture (X pur CSS, pas d'icône externe) — data-dismiss="alert" requis pour le comportement JS, voir JavaScript
