Démarrage

make install
make up

Puis ouvrir http://localhost:8092 (port configurable dans .env, clé APP_PORT).

Ports locaux (Docker)

APP_PORT=8092 et DB_EXPOSED_PORT=3311 par défaut — choisis pour ne pas entrer en conflit avec d'autres projets locaux. Un projet créé via bin/fork-project.sh reçoit automatiquement des ports libres différents.

Structure du dépôt

bin/console          # CLI (fourni par Framework\Kernel + Framework\Console\Application)
bin/fork-project.sh  # crée un nouveau projet indépendant à partir de celui-ci
src/App/             # Controller / Service / Repository de cette app
templates/           # vues Twig, dont layout.html.twig (navbar, blocks SEO)
assets/css/framework/    # tokens, reset, grille, composants CSS (voir Tokens, Grille...)
assets/js/framework/     # components.js — comportements JS des composants
config/app.php       # config lue par Framework\Config\Config (bundles assets, mailer, DB...)
docker/              # PHP 8.4 + nginx + MariaDB
docs/                # cette documentation

Architecture

Héritée du framework, non négociable : Controller → Service → Repository → DB. Détails complets (routing, DI, plugins, CLI, base de données...) : ../php-framework/docs/index.html — à consulter avant d'ajouter une feature ici plutôt que de redéfinir des conventions. Cette doc-ci ne couvre que ce qui est propre à ce dépôt (framework CSS/JS, conventions locales).
