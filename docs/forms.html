Formulaires

assets/css/framework/components/forms.css. Rendu live : /styleguide.

Champs texte / textarea / select

<div class="form-group">
    <label class="form-label" for="email">Email</label>
    <input class="form-control" type="email" id="email">
    <span class="form-text">Texte d'aide.</span>
</div>
ClasseRôle
.form-groupConteneur d'un champ (marge basse)
.form-labelLabel
.form-control<input>/<textarea> — focus, disabled/readonly gérés
.form-select<select>, flèche custom cross-navigateur
.form-control-sm / .form-control-lg (idem -select-)Tailles, miroir de .btn-sm/.btn-lg
.form-textTexte d'aide sous le champ

Validation

<input class="form-control is-invalid" type="text">
<div class="invalid-feedback">Ce champ est requis.</div>

.is-invalid / .is-valid sur le champ (bordure + anneau de focus colorés) ; .invalid-feedback / .valid-feedback sur l'élément suivant, affiché automatiquement via le sélecteur ~ (pas besoin de JS pour l'afficher/masquer).

Checkbox / radio / switch

<div class="form-check">
    <input class="form-check-input" type="checkbox" id="cgu">
    <label class="form-check-label" for="cgu">J'accepte les conditions</label>
</div>

<label class="form-switch">
    <input class="form-switch-input" type="checkbox" checked>
    <span class="form-check-label">Notifications actives</span>
</label>

.form-check-input utilise accent-color natif (pas de case reconstruite à la main). .form-switch-input est une bascule on/off pur CSS bâtie sur un input[type=checkbox].

Groupe d'input

<div class="input-group">
    <span class="input-group-text">https://</span>
    <input class="form-control" type="text">
</div>

.input-group accole un .form-control et un ou plusieurs .input-group-text (icône, texte, bouton) sans espace entre eux.
