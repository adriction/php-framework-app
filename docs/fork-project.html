fork-project.sh

bin/fork-project.sh crée un nouveau projet indépendant à partir de ce dépôt — un vrai fork git en dossier frère, pas une copie de fichiers. Pensé pour démarrer une app séparée (ex. un portfolio) qui réutilise la base (framework CSS/JS, structure, Docker) sans rester couplée au développement de php-framework-app lui-même.

Usage

bin/fork-project.sh <nom-du-projet> [app-port] [db-port]

bin/fork-project.sh monportfolio
bin/fork-project.sh monportfolio 8094 3313

Les ports sont optionnels : s'ils sont omis, le script scanne les ports déjà occupés (ss -tln) et choisit les premiers libres à partir de 8093/3312.

Ce qu'il fait

ÉtapeDétail
Clonegit clone vers ../<nom-du-projet> — historique complet préservé
Remotesupstream pointant sur ce dépôt, fetch-only (URL de push volontairement invalide — un git push sans argument va toujours vers origin, jamais vers php-framework-app) ; origin vers le futur dépôt GitHub du nouveau projet (à créer toi-même, voir ci-dessous)
Lien vers adrien/php-frameworkPasse d'un repository Composer path (symlink dev local) à un vrai lien vcs (clone git via SSH, branche dev-main) — le nouveau projet ne reflète plus les modifs locales du framework, composer update adrien/php-framework pour en récupérer une évolution
DockerAjoute openssh-client au Dockerfile, forwarde l'agent SSH de l'hôte (nécessaire au clone vcs d'un dépôt privé) à la place du mount local de php-framework, nom de projet Docker Compose et ports dédiés
IdentitéRenomme composer.json, README.md, CLAUDE.md (+ section expliquant ce workflow de fork), .env.example, la navbar et la page d'accueil (placeholder, pas de faux contenu)

Prérequis

  • Un agent SSH actif sur l'hôte avec la clé qui a accès aux dépôts GitHub concernés (ssh-add -l pour vérifier) — c'est cette même clé qui est forwardée dans le conteneur, aucune clé n'est copiée.
  • Le dépôt GitHub du nouveau projet doit être créé à la main, vide (sans README/gitignore auto-généré) avant de pousser — le script n'a pas accès à l'API GitHub (pas de gh CLI).

Après le fork

cd ../<nom-du-projet>
cp .env.example .env   # editer APP_SECRET
make install           # build + composer install (clone SSH de adrien/php-framework)
make console assets:build
git push -u origin main   # une fois le dépôt GitHub créé

Récupérer les évolutions en amont

Jamais automatique — à la demande, depuis le nouveau projet :

git fetch upstream
git merge upstream/main
