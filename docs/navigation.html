Navigation

assets/css/framework/components/navigation.css — navbar, onglets, fil d'Ariane. Comportements interactifs (menu mobile, changement d'onglet) : voir JavaScript. Rendu live : /styleguide (onglets/breadcrumb) et la navbar de cette doc elle-même n'en fait pas usage, mais celle de l'app (templates/layout.html.twig) oui.

Navbar

<nav class="navbar navbar-sticky">
    <a class="navbar-brand" href="/">Mon app</a>
    <button class="navbar-toggler" data-toggle="collapse" data-target="#nav">
        <span class="navbar-toggler-bar"></span>
        <span class="navbar-toggler-bar"></span>
        <span class="navbar-toggler-bar"></span>
    </button>
    <div class="navbar-collapse" id="nav">
        <div class="navbar-nav">
            <a class="nav-link active" href="/">Accueil</a>
            <a class="nav-link" href="/contact">Contact</a>
        </div>
    </div>
</nav>
ClasseRôle
.navbarBarre horizontale, fond + bordure basse
.navbar-stickyposition: sticky en haut de page
.navbar-brandLogo/nom, gras
.navbar-nav / .nav-linkListe de liens ; .active pour la page courante
.navbar-toggler / .navbar-collapseBurger + repli mobile (masqué < md, toujours visible ≥ md) — data-toggle="collapse" requis pour l'ouverture

Onglets

<div class="nav-tabs">
    <a class="nav-link active" data-toggle="tab" data-target="#p1">Vue</a>
    <a class="nav-link" data-toggle="tab" data-target="#p2">Docs</a>
</div>
<div class="tab-content">
    <div class="tab-pane active" id="p1">...</div>
    <div class="tab-pane" id="p2">...</div>
</div>

.nav-tabs réutilise .nav-link avec un indicateur de bordure basse active. Les panneaux .tab-pane doivent être frères sous un même .tab-content (le JS masque/affiche par groupe de frères).

Fil d'Ariane

<div class="breadcrumb">
    <span class="breadcrumb-item"><a href="/">Accueil</a></span>
    <span class="breadcrumb-item active">Page courante</span>
</div>

Séparateur / généré en CSS entre chaque .breadcrumb-item (sauf le premier) — pas besoin de le mettre dans le HTML.
