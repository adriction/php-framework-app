Grille

assets/css/framework/grid.css — système 12 colonnes construit sur CSS Grid (pas flexbox), API proche de Bootstrap pour rester familière. Breakpoints repris en dur (cohérents avec --breakpoint-* de tokens.css, qui ne peuvent pas être utilisées dans une condition @media) : sm 576 / md 768 / lg 992 / xl 1200 / xxl 1400.

Conteneur

<div class="container">...</div>       <!-- largeur max responsive -->
<div class="container-fluid">...</div> <!-- 100% -->

Row / Col — 12 colonnes

.row est un display: grid à 12 colonnes ; grid-auto-flow fait passer automatiquement les colonnes à la ligne dès que la somme des spans dépasse 12, comme le ferait flex-wrap.

<div class="row g-3">
    <div class="col-12 col-md-6 col-lg-4">...</div>
    <div class="col-12 col-md-6 col-lg-4">...</div>
    <div class="col-12 col-md-6 col-lg-4">...</div>
</div>
ClasseRôle
.col-1 → .col-12Span de base (s'applique dès xs), mobile-first
.col-{sm,md,lg,xl,xxl}-1 → -12Span à partir du breakpoint donné
.col-auto / .col-{bp}-autoColonne à largeur de contenu (fit-content)
.offset-0 → .offset-11 (+ variantes -{bp}-)Décale le début de colonne sans occuper l'espace

Espacement (gap)

ClasseEffet
.g-0 → .g-5gap (lignes + colonnes)
.gx-0 → .gx-5column-gap seul
.gy-0 → .gy-5row-gap seul

Alignement

.align-items-{start,center,end,stretch}, .justify-content-{start,center,end,between,around} sur .row.

CSS Grid utilitaire — mises en page libres

Pour les cas qui n'ont pas besoin du découpage en 12 (dashboards, listes de cards) :

<div class="grid grid-auto-fit g-3">
    <div class="card">...</div>
    <div class="card">...</div>
    <div class="card">...</div>
</div>
ClasseRôle
.griddisplay: grid + gap: var(--grid-gap)
.grid-cols-{2,3,4,6} (+ -md-/-lg-)Nombre de colonnes fixe, responsive
.grid-auto-fitAutant de colonnes de largeur min --grid-auto-min (240px par défaut, surchargeable) que la place le permet — sans media query, la dernière ligne s'étire pour combler l'espace
