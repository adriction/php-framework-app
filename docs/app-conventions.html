Conventions de l'app

Ce qui est propre à ce dépôt — pour l'architecture générale du framework (routing, Controller/Service/Repository, plugins), voir ../php-framework/docs/index.html.

Ajouter une page

Un Controller (src/App/Controller/) qui rend un template Twig, exactement comme documenté dans Controllers / Services / Repositories :

namespace App\Controller;

use Framework\Controller\AbstractController;
use Framework\Http\Response;
use Framework\Routing\Route;
use Twig\Environment;

class AboutController extends AbstractController
{
    public function __construct(Environment $twig)
    {
        parent::__construct($twig);
    }

    #[Route('/about', name: 'about', methods: ['GET'])]
    public function index(): Response
    {
        return $this->render('about/index.html.twig');
    }
}

Générateur : make console make:controller About. Le template étend templates/layout.html.twig :

{% extends 'layout.html.twig' %}

{% block title %}À propos{% endblock %}

{% block body %}
    <div class="container">
        <h1>À propos</h1>
    </div>
{% endblock %}

layout.html.twig fournit déjà la navbar, les blocks SEO/Open Graph (à valeur par défaut, une page ne surcharge que ce qui change — voir Vues (Twig) du framework) et le chargement des bundles CSS/JS.

Déclarer un bundle CSS/JS

Dans config/app.php, section assets (mécanisme complet : ../php-framework/docs/assets.html) :

'css' => [
    'app' => [
        'input' => [
            'assets/css/framework/tokens.css',
            'assets/css/framework/reset.css',
            'assets/css/framework/grid.css',
            'assets/css/framework/components/buttons.css',
            // ... un fichier par composant, voir assets/css/framework/components/
            'assets/css/app.css',   // styles propres à l'app, après le framework
        ],
        'driver' => \Framework\Assets\Driver\ConcatMinifyDriver::class,
    ],
],
'js' => [
    'app' => [
        'input' => [
            'assets/js/framework/components.js',
            'assets/js/app.js',
        ],
        'driver' => \Framework\Assets\Driver\ConcatMinifyDriver::class,
    ],
],

Ordre important : tokens avant tout ce qui les consomme, reset avant les composants, composants avant les styles propres à l'app (assets/css/app.css) qui peuvent alors surcharger le framework si besoin. Après toute modif : make console assets:build.

Style guide

/styleguide (src/App/Controller/StyleGuideController.php, templates/styleguide/index.html.twig) rassemble un exemplaire de chaque composant — à consulter après toute modification de tokens.css ou d'un fichier de components/ pour vérifier visuellement le rendu. Cette doc-ci (docs/) en est le complément écrit (classes/variables disponibles), pas un remplacement.
