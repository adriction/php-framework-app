php-framework-app

Application de référence construite sur adrien/php-framework. Cette documentation couvre ce qui est spécifique à ce dépôt : le framework CSS/JS maison (assets/css/framework/, assets/js/framework/) et les conventions de l'app. Pour l'architecture du framework lui-même (routing, Controller/Service/Repository, plugins, CLI...), voir ../php-framework/docs/index.html.

Framework CSS/JS

Design-token-driven, vanilla CSS/JS, sans dépendance externe (même esprit que le framework PHP : peu de dépendances, tout est compris). Rendu visuel live de chaque composant sur /styleguide — cette doc est la référence écrite (classes, variables, exemples de code) qui l'accompagne.

  • Tokens — couleurs, typographie, espacements, rayons, ombres, z-index, dark mode
  • Grille — .container, .row/.col-*, .grid/.grid-auto-fit
  • Boutons
  • Formulaires
  • Cards
  • Badges & alertes
  • Navigation — navbar, onglets, fil d'Ariane
  • Table
  • Modal & tooltip
  • Pagination, avatar, spinner
  • JavaScript — components.js, API par attributs data-*

Conventions de l'app
