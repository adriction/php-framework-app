Boutons

assets/css/framework/components/buttons.css — s'applique à <button>, <a class="btn"> ou <input type="submit">. Rendu live : /styleguide.

<button class="btn btn-primary">Primary</button>

Variantes couleur

Pleines : .btn-primary, .btn-secondary, .btn-success, .btn-danger, .btn-warning, .btn-info. Outline (fond transparent, se remplit au survol) : .btn-outline-primary, .btn-outline-secondary, .btn-outline-success, .btn-outline-danger, .btn-outline-warning, .btn-outline-info.

Tailles

ClasseEffet
(aucune)Taille de base
.btn-smCompact
.btn-lgGrand

États et modificateurs

Classe / attributEffet
disabled (attribut natif)Opacité réduite, pointer-events: none
.btn-loadingMasque le texte (garde la largeur), affiche un spinner CSS pur — à basculer en JS au moment d'une action async
.btn-blockLargeur 100%
.btn-iconCarré, pour un bouton icône seule

Groupe de boutons

<div class="btn-group">
    <button class="btn btn-outline-secondary">Jour</button>
    <button class="btn btn-outline-secondary">Semaine</button>
    <button class="btn btn-outline-secondary">Mois</button>
</div>

.btn-group accole plusieurs .btn sans espace, coins arrondis uniquement aux extrémités.
