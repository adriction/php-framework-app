Tokens

assets/css/framework/tokens.css — toutes les variables CSS consommées par les composants du framework. Ne jamais mettre de valeur en dur (couleur, espacement, rayon...) dans un composant : toujours passer par un de ces tokens. Remplacer les valeurs --color-primary-* suffit à rebrander tout le framework.

Couleurs — échelles primitives

Gris (--color-gray-50 à 900), accent (--color-primary-50 à 900), et trois nuances par statut (--color-success-50/500/600, idem warning/danger/info).

Couleurs — alias sémantiques

Ce que consomment réellement les composants (pas les échelles primitives directement) :

VariableRôle
--color-bgFond de page
--color-surfaceFond légèrement distinct (header de card, table striped...)

Grille / conteneur

--breakpoint-sm à -xxl (576/768/992/1200/1400px) sont documentées ici pour référence (accessibles en JS via getComputedStyle) mais ne peuvent pas être utilisées dans une condition @media (les custom properties ne sont pas résolues à cet endroit) — grid.css reprend ces valeurs en dur. Voir Grille. --container-max-width, --grid-columns, --grid-gap complètent le système.

Thème sombre

Les alias sémantiques ci-dessus sont resurchargés sous [data-theme="dark"] (choix explicite, ex. toggle utilisateur) et prefers-color-scheme: dark (préférence système, seulement si aucun thème n'est forcé). Les échelles primitives ne changent pas — seuls les alias (--color-bg, --color-text...) sont remappés.
